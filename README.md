# TilPro — толық жоба

Бұл папкаға React/Vite интерфейс, SQLite дерекқорлы Node.js backend және жиналған `dist` сайт кіреді.

## Компьютерде іске қосу

1. Node.js 22.13 немесе жаңасын орнатыңыз.
2. Осы папкада терминал ашыңыз да `npm install` орындаңыз.
3. Мұғалім шақыру коды мен портты орнатып, серверді іске қосыңыз:
   - PowerShell: `$env:TEACHER_INVITE_CODE="өзіңіз-таңдаған-код"; npm start`
   - macOS/Linux: `TEACHER_INVITE_CODE="өзіңіз-таңдаған-код" npm start`
4. Браузерден `http://localhost:8787` ашыңыз.
5. Мұғалім аккаунтын ашқанда 3-қадамдағы шақыру кодын енгізіңіз. Оқушылар тіркелу кезінде мұғалім логинін көрсете алады.

SQLite дерекқоры `data/tilpro.sqlite` ішінде жасалады. Басқа тұрақты дискіні көрсету үшін `DATABASE_PATH` орнатыңыз. Бұл файлды және тұрақты көшірмесін сақтаңыз.

## Авторизация және рұқсаттар

- Логин 3–32 таңба, латын әріптері, сандар және `_`; бас-кіші әріп айырмасы есептелмейді.
- Пароль кемінде 6 таңба. Пароль серверде `scrypt` арқылы тұзбен хэштеледі.
- Кіру сессиясы `HttpOnly` cookie арқылы беріледі.
- Мұғалім рөлі тек шақыру коды арқылы беріледі.
- Оқушы тек өз аккаунтына тіркелген мұғалімнің жариялаған жұмысын көріп, жауап бере алады.
- Дерек басқа пайдаланушыларға API деңгейінде шектеледі; браузер localStorage аккаунт не пароль хадгалахгүй.

## Басқа серверде жариялау

GitHub Pages тек статик сайт хосттайды, Node.js backend болон SQLite ажиллуулахгүй. Интерфейс ба API-г нэг origin-оос ажиллуулах Node.js хостингт байршуул. HTTPS ашигла. Орчны хувьсагч:

- `PORT` — хостын заасан порт.
- `DATABASE_PATH` — байнгын SQLite файл хадгалах диск.
- `TEACHER_INVITE_CODE` — нууц урилга код.
- `APP_ORIGIN` — cross-origin тохиргоо хэрэгтэй үед интерфейсийн origin; боломжтой бол ижил origin хэрэглэ.
- `NODE_ENV=production` — Secure session cookie асаана.

## Жоба құрамы

- `src/` — интерфейс пен оқу мазмұны
- `server/index.mjs` — авторизация, рөлдік API, тапсырмалар және SQLite
- `dist/` — соңғы жиналған сайт
- `launch.html` — браузерден файл ретінде ашылатын демо-нұсқа; тіркелу үшін сервер қажет

Бұл жоба аккаунт деректерін браузерлер арасында синхрондау үшін орналастырылған сервер мен тұрақты дерекқор дискісін қажет етеді.
