# TilPro

TilPro — қазақтілді оқушыларға орыс тілін тақырыптық сабақтар, деңгейге бейімделетін диагностика және қателерді қайталау арқылы үйрететін платформа.

## Жобаны жергілікті іске қосу

1. Node.js 22 немесе жаңасын орнатып, жоба бумасында `npm install` орындаңыз.
2. Мұғалім шақыру кодын орнатып, серверді іске қосыңыз:
   - PowerShell: `$env:TEACHER_INVITE_CODE="өз-кодыңыз"; npm start`
   - macOS/Linux: `TEACHER_INVITE_CODE="өз-кодыңыз" npm start`
3. `http://localhost:8787` адресін ашыңыз.

SQLite дерекқоры әдепкіде `data/tilpro.sqlite` жолында сақталады. Өндірістік серверде бұл файл тұрақты дискке жазылуы керек (`DATABASE_PATH`).

## GitHub Pages және сервер

GitHub Pages интерфейсті жариялайды, бірақ Node.js серверін немесе SQLite дерекқорын жүргізбейді. Сондықтан Pages-та сервер адресі берілмесе, қолданба браузердегі демо режимін қолданады; тіркелу мен құрылғылар арасында синхрондалатын аккаунт үшін backend хост қажет.

Backend-ті Node.js қолдайтын HTTPS хостқа орналастырып, мына орта айнымалыларын орнатыңыз:

- `PORT` — хост ұсынған порт.
- `DATABASE_PATH` — тұрақты сақтау орнындағы SQLite файлы.
- `TEACHER_INVITE_CODE` — мұғалім аккаунтын ашатын құпия шақыру коды.
- `APP_ORIGIN=https://kuanyshzhandosuli-design.github.io` — Pages-тен келетін API сұрауларына рұқсат беретін origin.
- `NODE_ENV=production` — қауіпсіз cookie параметрін қосады.

Содан соң репозиторийдің **Settings → Secrets and variables → Actions → Variables** бөлімінде `TILPRO_API_URL` айнымалысын қосып, мәніне backend-тің түбір HTTPS адресін жазыңыз (мысалы, `https://api.example.com`). `main` тармағына келесі push жасалғанда GitHub Actions осы адреспен интерфейсті қайта жинайды. Backend сессияны Bearer token арқылы да қабылдайды, сондықтан Pages пен бөлек API доменімен жұмыс істей алады.

## Негізгі мүмкіндіктер

- 5 күндік тақырыптық оқу аптасы және сақталатын тапсырма прогресі.
- Бастапқы диагностикадан кейінгі деңгей мен әлсіз тақырыпқа бейімделетін қосымша сұрақтар.
- Қателер паспорты және аралықпен қайталанатын белсенді жаттығулар.
- Сөздік, грамматика, оқу, диктант, сөйлеу және апталық қорытынды.
- Оқушы және мұғалім аккаунттары, сынып тапсырмалары және SQLite негізіндегі серверлік сақтау.
- Телефонға бейімделген интерфейс, PWA орнату және соңғы бет кэші.

Сөйлеу бөлімі браузердің қолжетімді сөйлеуді мәтінге айналдыру мүмкіндігін және қарапайым мәтіндік белгілерді қолданады; ол әзірге толық AI грамматика не айтылым бағалауы болып саналмайды.
